**Breasla** (private repository, in active development)

A Papers, Please-style document inspection game set in Wallachia, 1599–1601, during the reign of Michael the Brave (Mihai Viteazul).

You run a guild registration office. Recruits, merchants and travellers come to your window with papers. Check the seals, compare the faces, inspect the carts, and decide who gets through. The ledger records every decision and uses it against you later.

Rule engine that computes the correct decision from the documents and the active rule book
Data-driven, moddable content (JSON/PNG, English/Romanian)
Documents and faults generated from data (forged seals, mismatched descriptions)
Unity, C#, Aseprite; all pixel art and UI by me
Demo planned for Steam Next Fest, June 2027
